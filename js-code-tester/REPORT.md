웹 브라우저가 직접 자바스크립트 코드를 실행하고 테스트할 수 있는 **JS Runtime Live** 샘플 페이지 제작을 완료했습니다.

## 🚀 프로젝트 위치
*   **디렉토리**: `/Users/charlie/Codes/Dataprocessing_Example_Deid/js-code-tester`
*   **구성 파일**: 
    *   `index.html`: 구조 및 SEO 최적화 메타데이터
    *   `style.css`: 현대적인 다크 모드 및 Glassmorphism 디자인
    *   `script.js`: 자바스크립트 실행 로직 및 콘솔 인터셉트

## ✨ 주요 기능 및 특징
1.  **프리미엄 UI/UX**:
    *   현대적인 다크 테마와 매끄러운 그라디언트 적용.
    *   Hover 효과 및 마이크로 인터랙션을 통한 생동감 있는 인터페이스.
2.  **독립적인 실행 환경**:
    *   브라우저의 JS 엔진을 직접 활용하여 서버 없이 동작.
    *   `console.log`, `info`, `warn`, `error` 출력을 가로채어 커스텀 콘솔 영역에 실시간 표시.
3.  **개발자 친화적 도구**:
    *   **Tab 키 지원**: 에디터 내에서 들여쓰기 가능.
    *   **실행 단축키**: `Cmd + Enter` (Mac) 또는 `Ctrl + Enter` (Windows/Linux).
    *   **콘솔 관리**: 로그 개별 삭제 및 에디터 초기화 기능.

## 🛠 사용 방법
1.  `index.html` 파일을 웹 브라우저로 엽니다.
2.  왼쪽 **Source Code** 패널에 자바스크립트 코드를 입력합니다.
3.  **Run Code** 버튼을 클릭하거나 단축키를 사용하여 코드를 실행합니다.
4.  오른쪽 **Output Console**에서 실시간 실행 결과와 타임스탬프를 확인합니다.
