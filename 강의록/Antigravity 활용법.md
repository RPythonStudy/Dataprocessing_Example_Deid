Google의 **Antigravity**는 단순한 '바이브 코딩(Vibe Coding)'용 도구를 넘어, 여러 명의 AI 에이전트를 지휘하는 **'미션 컨트롤(Mission Control)'** 성격의 개발 플랫폼입니다. 단순히 코드를 짜달라고 하는 것 외에, 실무에서 강력하게 활용할 수 있는 4가지 핵심 시나리오를 정리해 드립니다.

---

## 1. 멀티 에이전트 오케스트레이션 (Agent Manager)

Antigravity의 가장 큰 차별점은 **'매니저 뷰(Manager View)'**입니다. 혼자서 여러 명의 주니어 개발자를 관리하는 '팀장' 역할을 수행할 수 있습니다.

* **병렬 작업 수행:** 한 에이전트에게는 '기존 레거시 코드의 리팩토링'을 시키고, 동시에 다른 에이전트에게는 '신규 기능에 대한 테스트 코드 작성'을 시킬 수 있습니다.
* **비동기 워크플로우:** 에이전트가 배경에서 작업을 수행하는 동안 사용자는 다른 파일을 수정하거나 기획을 진행할 수 있으며, 작업이 끝나면 에이전트가 보고서(Artifacts)를 제출합니다.

## 2. 브라우저 기반 자동 검증 및 UI 테스트

내장된 **'브라우저 에이전트'**를 활용하면 코드가 실제로 어떻게 작동하는지 시각적으로 확인하고 검증하는 과정을 자동화할 수 있습니다.

* **동작 기반 검증:** "로그인 페이지를 수정했으니, 실제로 브라우저를 띄워서 테스트 계정으로 접속해 봐"라고 지시하면 에이전트가 직접 브라우저를 조작하고 스크린샷이나 녹화 영상을 아티팩트로 남깁니다.
* **시각적 버그 수정:** UI 레이아웃이 깨지거나 버튼이 작동하지 않는 경우, 에이전트가 직접 화면을 보면서 코드를 수정하고 결과를 다시 확인합니다.

## 3. 커스텀 '스킬(Skills)'을 통한 워크플로우 자동화

반복되는 개발 업무를 **'Antigravity Skill'**로 정의하여 팀이나 개인의 생산성을 극대화할 수 있습니다.

* **문서화 자동화:** `SKILL.md` 파일을 설정하여 프로젝트 전체 구조를 분석하고 API 명세서(API.md)를 자동으로 최신화하는 스킬을 만들 수 있습니다.
* **배포 및 커밋 컨벤션 관리:** 코드를 수정할 때마다 특정 포맷의 Git 커밋 메시지를 생성하거나, 스테이징 서버에 자동으로 배포하는 스크립트를 에이전트가 실행하도록 설정할 수 있습니다.

## 4. 코드베이스 분석 및 지식 베이스(Knowledge Base) 구축

대규모 프로젝트에 처음 투입되었거나 복잡한 코드를 분석해야 할 때 유용합니다.

* **코드베이스 전체 인덱싱:** "이 프로젝트의 전체 구조와 핵심 도메인 로직을 요약해 줘"라고 요청하면, 에이전트가 전체 파일을 읽고 아키텍처 다이어그램이나 오버뷰 문서를 생성합니다.
* **자가 학습 기능:** 이전 작업에서 얻은 유용한 컨텍스트나 코드 스니펫을 지식 베이스에 저장하여, 다음 작업 시 더 정확하고 일관성 있는 코드를 제안받을 수 있습니다.

---

### Antigravity 활용 팁: `.antigravityrules` 설정

프로젝트 루트에 설정 파일을 두어 에이전트의 페르소나를 고정할 수 있습니다. 예를 들어, **"모든 답변은 한국어로 하고, 반드시 우리 팀의 Prettier 설정을 따를 것"**과 같은 규칙을 강제하면 훨씬 효율적인 협업이 가능합니다.

| 활용 모드 | 주요 역할 | 대상 사용자 |
| --- | --- | --- |
| **Editor View** | 페어 프로그래밍, 인라인 코드 생성 | 실시간 코딩이 필요한 개발자 |
| **Manager View** | 멀티 태스킹, 비동기 에이전트 관리 | PM 역할을 겸하는 시니어 개발자 |
| **Planning Mode** | 작업 분해 및 아티팩트 기반 검증 | 복잡한 기능을 설계해야 하는 아키텍트 |

혹시 현재 진행 중인 프로젝트에서 **구체적으로 어떤 자동화(예: 특정 API 연동, 배포 자동화 등)**를 원하시나요? 상황에 맞는 구체적인 프롬프트나 스킬 설정법을 알려드릴 수 있습니다.
